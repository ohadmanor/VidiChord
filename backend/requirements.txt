# VidiChord backend dependencies.
#
# Python 3.11 or 3.12 is recommended. Everything here except madmom installs
# cleanly on 3.13/3.14 as well, but madmom has no wheels beyond 3.12 and does
# not build from source against NumPy 2.x. Without it the app still runs:
# beat tracking falls back to librosa and chord fusion uses two engines
# instead of three. See README.md.

# --- web layer ---
fastapi>=0.110
uvicorn>=0.27
pydantic>=2.6

# --- audio acquisition ---
# The floor is the release that introduced the JavaScript-runtime interface
# this app configures. Keep yt-dlp current regardless: YouTube changes often,
# and a stale copy stops downloading long before it stops importing.
yt-dlp>=2026.7.4
requests>=2.31
# Descrambling a YouTube streaming URL means running the player's JavaScript,
# and yt-dlp ships the script that does it only for Deno and Bun. Node - the
# engine most machines actually have - needs this package, and without it the
# challenge goes unanswered and downloads are refused.
#
# Upgrade it in step with yt-dlp. yt-dlp checks the script's version and hash
# against its own vendored manifest and silently ignores a mismatch, which
# looks exactly like not having the package at all. The release build asserts
# the two agree; `pip install -U yt-dlp yt-dlp-ejs` keeps them that way.
yt-dlp-ejs>=0.8

# --- transcription ---
# 1.1 is the floor that knows the "large-v3-turbo" model alias.
faster-whisper>=1.1

# --- audio analysis ---
librosa>=0.10
soundfile>=0.12
numpy>=1.26
scipy>=1.11

# --- development ---
# pytest>=8.0

# --- madmom (optional) ---
# Deliberately not listed here: it cannot be installed by a plain `pip install
# -r`. The PyPI sdist ships C files generated by an old Cython that include
# longintrepr.h, a header removed in Python 3.12, and its setup.py imports
# Cython without declaring it as a build dependency. setup.bat installs it
# from git with --no-build-isolation, which works. Requires a C compiler and
# Python 3.12 or older.
#
# Without madmom the app still runs: bar lines are estimated from onset energy
# rather than tracked, and chords are fused from two engines instead of three.
